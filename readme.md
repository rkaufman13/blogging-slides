# Why a dev blog is your career's secret weapon

Thanks for your interest. I'm a huge proponent of blogging about tech, for all the benefits that writing and publishing can convey for your career. To learn more, clone this repo and open its index.html file in your browser.

### Doteki 

This software makes it easy to create a dynamic Github profile. It doesn't only hook into your new blog's RSS feed, but its ability to do that is one of its coolest features (in my opinion).
